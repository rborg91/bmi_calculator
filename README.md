# BMI Calculator

Calculate your BMI and the BMI category that it falls within using this python script.
Originally created as a beginner project for myself, it was updated in February
2026 with the knowledge and skills I have since gained from the time of this project's
creation. But there is always room for improvement with this one.

## Requirements

- Python

## Installation

Clone this repository to your local machine and change into the directory.

## Usage

To run the script, run the following command:

    python bmi_calculator.py

Follow the onscreen commands to find out your BMI.
